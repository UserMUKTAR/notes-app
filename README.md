# Notes App

Full-stack Notes Management Application built using Java Spring Boot and React.

## Project Structure

* backend/ → Spring Boot REST API
* frontend/ → React frontend

## Features

* Create Notes
* Update Notes
* Delete Notes
* Retrieve Notes

## Tech Stack

* Java
* Spring Boot
* React
* PostgreSQL / MySQL
* Maven
* Vite

## Backend Run

cd backend
mvn spring-boot:run

## Frontend Run

cd frontend
npm install
npm run dev
